# Clasificador-de-voz
Aplicación de Machine Learning en un clasificador de Voz humana (Hombre/Mujer)

Contamos con las caracteristicas acusticas de voz obtenidas de la base de datos de UIC Machine Learning

Queremos predecir con base en las características la voz pertenece a la de un hombre o una mujer 

El conjunto de datos tiene las siguientes variables correspondiente a características acústicas de registro de voz.

meanfreq: Frecuencia media (en kHz).   
sd: Desviación estándar de la frecuencia.   
median: Mediana de la frecuencia.   
Q25: Primer cuartil (percentil 25) de la frecuencia.   
Q75: Tercer cuartil (percentil 75) de la frecuencia.   
IQR: Rango intercuartílico de la frecuencia.   
skew: Asimetría (medida con la asimetría espectral).   
kurt: Curtosis (medida con la curtosis espectral).   
sp.ent: Entropía espectral.   
sfm: Planitud espectral (spectral flatness).   
mode: Moda de la frecuencia.   
centroid: Centroide de frecuencia.   
meanfun: Promedio de la frecuencia fundamental medida acústicamente en la señal de voz.   
minfun: Frecuencia fundamental mínima.  
maxfun: Frecuencia fundamental máxima.   
meandom: Promedio de la frecuencia dominante.  
mindom: Frecuencia dominante mínima.   
maxdom: Frecuencia dominante máxima.   
dfrange: Rango de la frecuencia dominante.  
modindx: Índice de modulación.   
label: Etiqueta correspondiente a si la voz pertenece a una mujer (female) o a un hombre (male).
